## 二、需求基线与两次用户批准的降级

基线 9 项：投屏 / 三键导航 + 低频点击 / 剪贴板双向含图片 / 无音频 / Wi-Fi 优先 / 最多 3 台 / 投屏界面含三键 / 视觉息屏 / 原生级流畅。

两次降级都是**用户本人拍板**，契约里记有 `approved_by`，不得偷偷改回：

1. **DEC-08 / INV-13**：反控收窄为「三键导航 + 低频点击（<200ms 单点）」。hdc 注入、API 26 `inputEventClient`、ACL 提权三条已真机判死。
2. **INV-05 视觉息屏**：设备屏肉眼呈黑、PC 端仍实时刷新，不要求物理休眠。A1/A2/A3/B 四条物理息屏路线实测排除；运行期 `hdc shell` 唤屏实测会踢掉 fport 会话（30s 出帧 8→0），明令禁止。

## 三、架构与关键实现

- **设备端**：ArkTS + C++（NAPI）+ AVScreenCapture + OH_VideoEncoder 零拷贝；采集 so 为 `screen_casting.so`（242 KB），触控用 `agent.so`（586 KB）——**推错会绑不上 `@scrcpy_grpc_socket`**。
- **PC 端**：C# / .NET 8 + WPF + Media Foundation 硬解 + D3DImage 上屏；单文件发布 `HarmOsWin.exe`。
- **hdc 桥**：所有 hdc 调用必须经独立控制台进程 `HarmOsWin.HdcBridge`（stdin/stdout 行式 JSON），`HdcRunner` 只是薄客户端。WPF 内直接跑 hdc 的九种常规排法全部失败（控制台 8/8 全过、WPF 必卡且位置随机），勿再重试。桥需 `ReadBridgeLine` 带超时，否则阻塞会锁死 `HdcSerial` 全局锁。
- **传输**：LAN + HWP v1.1 UDP 双通道 + 30ms 心跳；GATE-L0 通过，故**不上 P2P**。gRPC h2c 走 fport；fport 规则存在 hdcd server 内存，server 一死即成「僵尸监听」（端口 LISTENING 但 connect refused）。
- **注入**：`AccessibilityExtensionAbility`（服务名 `LowFreqAccessibility`），需用户本人到「设置 → 辅助功能 → 扩展服务 → 已安装的服务」手动开启。
- **剪贴板**：设备→PC 走 `HCLIP` UDP 18766 + PasteButton 一次性读权限；PC→设备走 `aa start -a ClipSetAbility -b com.harmos.mirror --ps cliptext <base64>` 真写系统 `pasteboard`，不是敲字（敲字仅回退）。
- **窗口贴合**：`SwitchTo(id, refitWindow=true)` 仅由两个用户点击入口传入，Loaded 延迟执行 `FitWindowToDevice() → UpdateLayout() → ApplyStretchForAspect()`。勿把贴合挪回同步路径（11-13 曾致进程消失），勿删 `UpdateLayout()`。

## 八、开发与维护硬规则

1. **调试一律走无线**，统一 `scripts\hdcw.sh`，**禁止 USB 调试**（会被 hdcd 踢掉 TCP 通道）。hdc 严格串行、每次前必 `tconn`；Git Bash 需 `MSYS2_ARG_CONV_EXCL='*'`；中文绝对路径用相对名；不用 `hdc tmode port`。
2. **编译 / 装机 / 启动须用户当次逐次授权**，改完代码 ≠ 可以编译。完成鸿蒙工程构建/安装/启动/截图后，回复首行标注执行通道（PC 端 C#/.NET 8 WPF 走命令行，MCP 不适用）。
3. **工具会话里启动 WPF 会被作业对象连带杀掉**，须 `Start-Process explorer.exe -ArgumentList '"<exe>"'` 由桌面外壳拉起。
4. **启动连不上四层防线勿删**：`MainWindow.cs:905` 整体自愈重试 → `HdcTargetResolver` 空列表按 IP 分缓存 tconn + 候选重试 + 端口扫描 → 桥 `RunHdc` 会话失效自动 tconn 重试一次 → 双启用配置 + 4 份配置副本 md5 一致 + 根目录 exe 与桥同目录。三条禁止回退：手机 `enabled` 勿改 false、`capture` 勿改 `hap`、IP 勿改回 103。
5. **禁止拿用户私人应用当试验场**，自测只用自有 HAP 调试页（`InputProbePage.ets` / `ClipSetAbility`）。
6. **清 tmp 前必做文档引用检查**；`logs/`、`.hdcw/`、4 份配置副本、`tmp/refout/`、`clip-anchor.json`、被引用证据文件、`pc/` 下 bin/obj 一律别碰。
7. Windows 送回收站**禁用 `Add-Type`**（安全策略拦运行时编译 .NET），用 Python ctypes `SHFileOperationW` + `FOF_ALLOWUNDO`，每批 ≤10 逐批校验；先做逐文件 md5 全量副本，确认成功后才删。
8. 设备端**禁用管道 `|`**（grep 等空 stdin 出 0 字节），用 `grep xxx /proc/net/unix`、`ps -ef`；`hdc file send` 用相对名 + 透传 WorkingDirectory + 先 `rm -f`。判进程存活用 `Process.HasExited` 轮询，不用 `tasklist | grep`。
9. 色彩公式 BT.601 limited 不改；参考项目（ohscrcpy / hnscrcpy / lanlink / oink）只借鉴思路，代码一行不能抄，红线见 `docs/参考项目-能力清单.md`。
